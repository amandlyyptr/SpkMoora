# Sistem Pendukung Keputusan

Website Sistem Pendukung Keputusan menggunakan metode MOORA.

# Fitur

- Pengelolaan data alternatif
- Pengelolaan data kriteria
- Perhitungan menggunakan metode MOORA
- Menampilkan hasil perangkingan alternatif
- Menampilkan hasil keputusan

# Tools & Teknologi

- PHP
- MySQL
- HTML
- CSS
- JavaScript

# Cara Menjalankan

1. Clone repositori ini
2. Letakkan folder project pada web server seperti XAMPP
3. Buat database MySQL
4. Import file database yang tersedia
5. Sesuaikan konfigurasi database
6. Jalankan project melalui browser

# Hasil

Website dapat digunakan untuk melakukan proses Sistem Pendukung Keputusan menggunakan metode MOORA dan menampilkan hasil perangkingan alternatif.
